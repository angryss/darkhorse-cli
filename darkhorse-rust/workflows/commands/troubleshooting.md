# Troubleshooting Command

> Diagnose and resolve project issues.

## Usage

```bash
darkhorse-rust troubleshoot
```

## What It Does

Launches troubleshooting using the Troubleshoot agent. The agent:

1. Gathers context about the reported issue
2. Traces through the layer stack
3. Identifies root cause and applies fix
4. Verifies the fix

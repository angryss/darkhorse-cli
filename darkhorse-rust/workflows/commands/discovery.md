# Discovery Command

> Run a discovery session for a Rust/Tauri desktop project.

## Usage

```bash
darkhorse-rust discover
```

## What It Does

Launches a discovery session using the Discover agent. The agent:

1. Reads project context and current domain model
2. Analyzes bounded contexts and entity candidates
3. Produces a discovery report with recommendations

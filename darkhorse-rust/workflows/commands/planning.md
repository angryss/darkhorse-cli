# Planning Command

> Create or refine implementation plans for project requirements.

## Usage

```bash
darkhorse-rust plan
```

## What It Does

Launches a planning session using the Plan agent. The agent:

1. Loads the target requirement from the roadmap
2. Analyzes current codebase for impact
3. Creates or updates a proposal in `openspec/changes/`

See `openspec/specs/workflow/skills/planning.md` for the full planning skill specification.

## Longer Launch Announcement

Angry Software Solutions is sharing DarkHorse CLI as a public alpha.

DarkHorse is an AI-native engineering framework for structured software delivery. The project focuses on making AI-assisted development more explicit and repeatable through open specification workflows, developer workflow automation, software scaffolding, and reusable engineering context.

The current public-alpha release is intended for exploration and feedback. It includes early workflow and scaffolding patterns for teams that want clearer structure around planning, implementation, review, and reuse. DarkHorse is not being presented as a finished platform or a production guarantee. It is a practical framework under active development.

We are especially interested in feedback on the clarity of the workflows, the usefulness of the scaffolders, and the kinds of engineering context that help teams work more effectively with AI tools.

GitHub: https://github.com/angryss/darkhorse-cli

## GitHub Release Description Draft

DarkHorse CLI public alpha introduces the project as an AI-native engineering framework for structured software delivery.

This release focuses on early access to the framework's open specification workflows, developer workflow automation patterns, scaffolders, and reusable engineering context. It is intended for evaluation, feedback, and iteration.

Please treat this as public-alpha software. Workflow conventions, scaffolder behavior, and documentation may change as the project matures.

Useful feedback includes:

- Where the workflows are clear or confusing.
- Which scaffolders are most useful.
- Missing context that would improve AI-assisted development.
- Documentation gaps for first-time users.

Repository: https://github.com/angryss/darkhorse-cli

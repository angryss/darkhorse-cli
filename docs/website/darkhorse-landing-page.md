## Short Product Summary

DarkHorse is an AI-native engineering framework from Angry Software Solutions. It helps engineering teams organize AI-assisted development around open specifications, repeatable workflows, software scaffolding, and reusable engineering context.

DarkHorse is currently in public alpha. The project is ready for exploration, feedback, and early workflow design, but it should be evaluated carefully before use in production delivery pipelines.

## Key Features

- Open specification workflows for planning and delivering software changes.
- Developer workflow automation that keeps project context, implementation steps, and review expectations explicit.
- Software scaffolding for common project shapes, including .NET scaffolder, Java scaffolder, and Rust/Tauri scaffolder workflows.
- Reusable engineering context for teams working with AI-assisted development tools.
- Engineer-first documentation that favors clear contracts, repeatable steps, and practical adoption over opaque automation.

DarkHorse is in public alpha. APIs, workflow conventions, and scaffolders may change as the framework is tested against real engineering workflows. Feedback is welcome, especially around documentation clarity, scaffolder coverage, and workflow ergonomics.

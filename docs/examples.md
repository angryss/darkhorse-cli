# Example Guidance

DarkHorse does not currently maintain a dedicated root `examples/` directory.

For public alpha, examples should be generated intentionally and kept small. They should demonstrate the stable scaffolder entry points without becoming large secondary applications.

## Planned Examples

- .NET minimal API project generated by `darkhorse-dotnet`.
- Java/Quarkus API project generated by `darkhorse-java`.
- Rust/Tauri desktop project generated by `darkhorse-rust`.
- OpenSpec workflow asset walkthrough showing generated `openspec/`, `context/`, `AGENTS.md`, rules, guides, and workflows.

## Contributor Guidance

Use ignored folders such as `tmp/` or `test-run-*` for local scaffold output. Do not commit ad hoc generated projects as examples.

Before adding a committed example, document:

- the exact scaffolder command used to generate it
- which generated files were intentionally modified
- how to validate the example after cloning
- which DarkHorse version or package commit generated it

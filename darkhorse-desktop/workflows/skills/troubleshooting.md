# Skill: Diagnostic Input

## Authority

Diagnostics and work-item status are non-authoritative input. VEP remains lifecycle, readiness, risk-tier, proof, review, and closure authority.

## Method

1. Reproduce and record expected/actual behavior, affected paths, and observed output.
2. Identify a bounded correction without changing A1 or projections directly.
3. If governed meaning changes, amend canonical A1 through the adapter and regenerate projections.
4. Rerun the affected installed Darkhorse CLI operation and preserve the exact result.
5. Never turn a fixed symptom, passing local test, or cached view into VEP completion.

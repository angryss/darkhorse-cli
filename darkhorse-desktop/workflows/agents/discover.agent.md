# Discover input agent

Load the Discovery skill. Preserve observations as non-authoritative draft data, then invoke the installed Darkhorse CLI `discover` command for the selected generated-project root. That adapter resolves only project-local VEP.

Never decide readiness, select Tier 1/2/3, advance a Desktop phase, or convert a cached result into current truth. Return the delegated exit code, stdout, and stderr without reinterpretation.
